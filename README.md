# Car Info — บันทึกการดูแลรถ + คำนวณอัตราสิ้นเปลือง

เว็บแอป (PWA) สำหรับมือถือ ธีมแดง-ดำ Aurora / Liquid Glass

- **เติมน้ำมัน**: จดวันที่ เลขไมล์ ลิตร ราคา (กรอก 2 ใน 3 ช่อง ช่องที่ 3 คำนวณให้)
- **อัตราสิ้นเปลือง**: km/L, L/100km, บาท/km — เฉลี่ย, ครั้งล่าสุด, ดีสุด/แย่สุด + กราฟ
- **ซ่อมบำรุง**: น้ำมันเครื่อง ยาง เบรก แบตเตอรี่ ภาษี/พ.ร.บ. ฯลฯ พร้อม **แจ้งเตือนครั้งถัดไป** (ตามเลขไมล์และ/หรือวันที่)
- **ค่าใช้จ่ายรายเดือน** แยกน้ำมัน/ซ่อมบำรุง
- **หลายคัน**: สลับรถได้จากแถบด้านบน
- **ข้อมูลอยู่ในเครื่องเท่านั้น** + ส่งออก/นำเข้าไฟล์สำรอง (.json) และ CSV สำหรับ Excel
- **ใช้งานออฟไลน์ได้** หลังเปิดครั้งแรก (ผ่าน service worker)

## วิธีคำนวณ km/L (เต็มถังถึงเต็มถัง)

1. เติมเต็มถัง แล้วจดเลขไมล์ เช่น 10,000 km
2. เติมเต็มถังครั้งถัดไปที่ 10,500 km ได้ 35 ลิตร
3. 35 ลิตรคือน้ำมันที่ใช้ไปใน 500 km → 500 ÷ 35 = **14.3 km/L**

- เติม **ไม่เต็มถัง** ระหว่างทาง → ลิตรจะรวมเข้ากับช่วงถัดไป
- **ลืมจด** การเติมครั้งไหน → ติ๊ก “ลืมจดครั้งก่อน” ช่วงนั้นจะไม่ถูกนำมาคิด
- ค่าเฉลี่ยรวม = ระยะทางรวม ÷ ลิตรรวม (ไม่ใช่เอาค่า km/L มาเฉลี่ยกันตรงๆ)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้าเว็บ |
| `css/styles.css` | ธีมและหน้าตา (แก้สีได้ที่ `:root` ด้านบน) |
| `js/calc.js` | สูตรคำนวณทั้งหมด (ไม่ยุ่งกับหน้าจอ → เทสต์ง่าย) |
| `js/store.js` | บันทึก/โหลดข้อมูลใน localStorage และสำรองข้อมูล |
| `js/charts.js` | กราฟ SVG (ไม่ใช้ไลบรารีภายนอก) |
| `js/app.js` | หน้าจอ ฟอร์ม และการกดปุ่มต่างๆ |
| `sw.js`, `manifest.webmanifest`, `icons/` | ทำให้ติดตั้งบนมือถือและใช้ออฟไลน์ได้ |
| `tests/calc.test.js` | เทสต์สูตรคำนวณ |

ไม่มีขั้นตอน build — เป็นไฟล์ HTML/CSS/JS ธรรมดา

## รันบนคอมพิวเตอร์

```bash
npm test          # รันเทสต์สูตรคำนวณ (ต้องมี Node.js 18+)
npm start         # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
# หรือ: python3 -m http.server 8080
```

เปิดไฟล์ `index.html` ตรงๆ ก็ใช้ได้ แต่โหมดออฟไลน์/ติดตั้งจะทำงานเฉพาะเมื่อเปิดผ่าน http(s)

## ใช้บน iPhone

ต้องเอาแอปขึ้นเว็บที่เป็น **https** ก่อน (เช่น GitHub Pages, Netlify, Cloudflare Pages) แล้ว:

1. เปิดลิงก์ด้วย **Safari**
2. กดปุ่ม **แชร์** → **เพิ่มไปยังหน้าจอโฮม**
3. เปิดจากไอคอนทุกครั้ง (ข้อมูลในแอปบนหน้าจอโฮมแยกจาก Safari ปกติ)

> ⚠️ ข้อมูลเก็บในเครื่องเท่านั้น ถ้าลบแอป/ล้างข้อมูลเบราว์เซอร์/เปลี่ยนเครื่อง ข้อมูลจะหาย
> ให้กด **ส่งออก (สำรอง)** ในหน้า “รถ & ตั้งค่า” เป็นระยะ แล้วเก็บไฟล์ไว้ใน Files / iCloud Drive

## อัปเดตแอปในอนาคต

เมื่อแก้ไฟล์ใดๆ ให้เปลี่ยน `VERSION` ใน `sw.js` (เช่น `carinfo-v1.0.1`) เพื่อให้เครื่องที่ติดตั้งแล้วโหลดไฟล์ใหม่
